# CyberNexus 2050

CyberNexus 2050 is a fictional cyborg project that explores a future where humans and intelligent machines work together seamlessly.

## Inspiration
This project is inspired by the spirit of innovation, technology, and futuristic thinking showcased by Techfest IIT Bombay.

## Features
- Futuristic cyber-themed UI
- Responsive landing page
- CyberNexus project overview
- Core feature showcase
- Technology overview section
- Project statistics
- Inspiration section

## Technologies Used
- HTML5
- CSS3

## Project Vision
CyberNexus 2050 aims to imagine a world where artificial intelligence, robotics, and human intelligence merge to unlock new possibilities for humanity.
